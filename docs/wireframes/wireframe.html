Notice 등록 / 수정

/notices/new · /notices/{id}
ADMIN-04
  1. 1기간. 날짜와 시각을 입력한다. 종료 시각이 지나면 목록과 지도에서 자동으로 내려간다. 종료 시각이 없으면 Private으로 바꿀 때까지 표시한다.
  2. 2본문은 요약만 입력하고, 원문 URL을 필수로 받는다.
  3. 3Official source를 체크한 공지에만 Official 표시가 붙는다.
  4. 4위치는 선택 항목이다. 지정하지 않으면 목록에만 나온다. 위치 설명은 상세의 Location에 표시한다. Event 폼은 같은 배치에 일시와 장소 이름을 받는다. ADMIN-03
